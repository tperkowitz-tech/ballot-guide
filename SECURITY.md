# Security and privacy

This project is a static web page plus prompt files. It has no server, accounts or database, and it collects no data. The web kit stores your progress only in your own browser; your address goes only into the ballot-lookup question (and its optional double-check) that you paste into an AI chat yourself. The page loads nothing from other sites (no fonts, ads or scripts); GitHub Pages, which hosts it, sees visitors' IP addresses like any website host. "Start over" erases everything saved in the browser.

If you find a way the page could leak personal information, run untrusted code, or mislead voters about how voting works, please report it privately through GitHub's **Report a vulnerability** button on the [Security tab](https://github.com/tperkowitz-tech/ballot-guide/security). Do not open a public issue for these, and do not include anyone's personal details in a report.
